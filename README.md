# E-Com Margin Tool

A micro-utility to clean CSV product data and calculate profit margins instantly.

**Live Link:** [https://parthiv95.github.io/ecom-margin-tool/](https://parthiv95.github.io/ecom-margin-tool/)

## Tools included:
- index.html: Web-based margin calculator.
- reconcile_tool.py: Automated CSV audit script.
- idea_scanner.py: Trend-spotting automation.
